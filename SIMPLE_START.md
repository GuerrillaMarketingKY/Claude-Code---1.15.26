# ClickUp Monitor - Super Simple Version

## 🚀 How to Use

**Just double-click this file:**
```

```

That's it! It will:
1. Check all your ClickUp tasks
2. Find approaching deadlines
3. Find stale tasks (no updates in 24h)
4. Post reminder comments
5. Show you what it did
6. Stop automatically

- **Stale Tasks** - No updates in 24+ hours

## PRIORITY ISSUES TO WATCH FOR

- **BLANK PAGES** - Pages with only header + footer, no body content. Most common with page builders (Elementor/WPBakery) that weren't migrated properly.
- **404 ERRORS** - Pages on production that return "Not Found" on staging. Means content migration was incomplete.
- **HARDCODED PRODUCTION URLS** - Links/images pointing to www.beachybarns.com instead of staging domain. WordPress stores full URLs in the database - a search-replace is needed.
- **BROKEN IMAGES** - Images that don't load. Check both media library images and CSS background images.
- **PHP/DATABASE ERRORS** - Visible "Fatal error", "Warning", "Notice", or "Error establishing a database connection" on any page.
- **MISSING PLUGINS** - Page builder plugins (Elementor, WPBakery, Divi) or form plugins (Gravity Forms, WPForms, CF7) not migrated = broken/blank pages.
- **3D BUILDER BROKEN** - The 3D Shed Builder is linked from many pages. Verify it loads and works on staging.
- **INVENTORY MISMATCH** - Inventory items may differ if staging database is from an older snapshot.
- **WRONG CITY NAMES** - Location pages often have copy-paste errors where one city's name appears on another city's page.
- **FORMS NOT WORKING** - Contact form, quote request form, and catalog download form should all submit to staging (not production).
